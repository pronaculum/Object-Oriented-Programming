도형 데이터 변경 없이 상태와 기하학적 지표를 계산하는 API

기하학적 관계 조회 및 연산 API

도형 간의 현재 상태를 실시간으로 분석하여 반환하는 메서드 구성
메서드명 (Method) 반환 타입 매개변수 (Parameters) 설명 (Description)
getSpatialRelation SpatialRelation (Shape o1, Shape o2) 두 객체 간의 현재 기하학적 관계(각도/만남/평행/일치)를 판단하여 반환합니다.
calculateAngle double (Shape o1, Shape o2) 두 객체 사이의 사잇각 크기를 계산하여 반환합니다. (각도 관계 분석용)
getIntersection Point2D (Shape o1, Shape o2) 두 객체가 만나는 교점의 좌표를 정확히 계산하여 반환합니다. (만남 관계용)
hasRelation boolean (Shape o1, Shape o2, Relation type) 두 객체가 지정한 특정 기하학적 조건이나 관계를 만족하는지 여부를 검증합니다.

02. 수정 및 변경 메서드

도형의 속성을 제어하여 의도적인 기하학적 관계로 강제 정렬하는 API

도형 상태 수정 및 정렬 API

도형 객체의 좌표나 기울기를 실시간으로 조정하여 대상을 동적으로 제어

modifyRelation

boolean (Shape o1, Shape o2, Relation target)

두 객체의 상대적 위치나 각도를 계산하고 조절하여, 사용자가 목표로 하는 타겟 관계(Relation) 상태로 강제 변경합니다.

alignParallel

void (Shape o1, Shape o2)

두 객체의 기울기(Slope) 벡터를 동일하게 맞춰 평행 상태가 되도록 한쪽 혹은 양쪽 도형의 방향 데이터를 수정합니다.

alignCoincidence

void (Shape o1, Shape o2)

두 객체의 기준 좌표값과 방향 벡터를 완벽하게 동일 선상으로 일치시켜 일치(Coincidence) 상태로 수정 보정합니다.

객체지향 설계의 핵심 성과 (SOLID)

본 설계 초안이 갖는 구조적 특장점
  • 다형성(Polymorphism) 극대화
    모든 메서드가 상위 추상 클래스나 인터페이스인 Shape 타입을 파라미터로 받아, 향후 원(Circle), 삼각형(Triangle) 등이 추가되어도 메서드 시그니처를 유지할 수 있습니다.
  • 확장성 중심 설계 (OCP)
    새로운 기하학적 관계 알고리즘이 필요할 때 기존 코드를 수정하는 대신 Relation 인터페이스 전략 패턴 형태로 확장이 가능합니다.
  • 명확한 책임 분리 (Separation of Concerns)
    도형 데이터 자체를 담는 Entity 패키지와 연산을 제어하는 Function 패키지가 명확히 구분되어 협업 및 단위 테스트(Unit Test) 생산성이 높습니다.
